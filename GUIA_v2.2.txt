FEATURE 1: COPIAR TEXTOS DA TABELA (Ctrl+C)
═══════════════════════════════════════════════════════════════════════════

COMO USAR:
1. Clique em qualquer linha da tabela para selecionar
2. Pressione Ctrl+C
3. O conteúdo é copiado para a área de transferência
4. Cole em qualquer aplicação (Ctrl+V)

EXEMPLO:
┌────────────────────────────────────────────┐
│ # | IP | MAC | Hostname | ... | Serviços  │
├────────────────────────────────────────────┤
│ 1 │192.168.1.1│AA:BB:CC│router.local│...│HTTP(80),SSH(22)│
    ↓ Ctrl+C ↓ 
    Clipboard: 1 | 192.168.1.1 | AA:BB:CC:DD:EE:FF | router.local | ...

═══════════════════════════════════════════════════════════════════════════
FEATURE 2: RENOMEAR DISPOSITIVOS (Duplo-clique na coluna MAC)
═══════════════════════════════════════════════════════════════════════════

COMO USAR:
1. Clique duas vezes (duplo-clique) em qualquer célula da coluna MAC
2. Uma janela aparece pedindo um apelido
3. Digite o nome desejado (ex: "Router VIVO", "Impressora HP", etc.)
4. Clique "Salvar" ou pressione Enter

EXEMPLO:
┌──────────────────────────────────────────────┐
│ MAC (duplo-clique) → Abre janela:           │
│                                              │
│ MAC: AA:BB:CC:DD:EE:FF                      │
│ Novo apelido: [_________________]           │
│              [Salvar] [Cancelar]            │
│                                              │
│ Digite: "Router Principal"                  │
└──────────────────────────────────────────────┘

ONDE OS APELIDOS SÃO SALVOS:
✓ Arquivo: config.json (na mesma pasta do programa)
✓ Persistem entre execuções do programa
✓ Um apelido por MAC (identificador único)

EXEMPLO config.json:
{
  "ping_attempts": 4,
  "scan_interval": 60,
  "device_nicknames": {
    "AA:BB:CC:DD:EE:FF": "Router Principal",
    "11:22:33:44:55:66": "Impressora HP",
    "99:88:77:66:55:44": "Celular João"
  }
}

FEATURE 3: ABRIR SERVIÇOS EM JANELA (Clique direito + Porta)
═══════════════════════════════════════════════════════════════════════════

COMO USAR:
1. Clique direito em qualquer célula da coluna "SERVIÇOS"
2. Um menu popup aparece com as portas descobertas
3. Clique em uma porta para abrir

EXEMPLO:
┌─────────────────────────────────────┐
│ Serviços │ Clique direito           │
│HTTP(80)  ├──────────────────────────┤
│SSH(22)   │ Portas de 192.168.1.1   │
│MySQL(3306)├─────────────────────────┤
│HTTPS(443)│ HTTP (80)    ← clique   │
│          │ SSH (22)     ← clique   │
│          │ MySQL (3306) ← clique   │
│          │ HTTPS (443)  ← clique   │
│          └─────────────────────────┘

O QUE ACONTECE AO CLICAR:
✓ HTTP(80)      → Abre http://IP:80 no navegador
✓ HTTPS(443)    → Abre https://IP:443 no navegador
✓ SSH(22)       → Tenta abrir ssh://IP
✓ MySQL(3306)   → Abre http://IP:3306 (PhpMyAdmin, etc.)
✓ Outras portas → Abre http://IP:PORTA (fallback)

NOTAS TÉCNICAS
═══════════════════════════════════════════════════════════════════════════

1. Arquivo de Configuração:
   - config.json é criado automaticamente
   - Armazena: ping_attempts, scan_interval, device_nicknames
   - Está gitignore para não vazar dados pessoais

2. Persistência de Apelidos:
   - Os apelidos são salvos imediatamente ao clicar "Salvar"
   - Não precisa reexecutar o programa para carregar
   - São identificados unicamente pelo MAC (não pelo IP)

3. Proteção contra Mudanças de IP:
   - Um mesmo dispositivo pode ter IPs diferentes no tempo
   - O apelido está vinculado ao MAC (hardware)
   - Se o IP mudar, o apelido continua vinculado

EXEMPLO DE USO COMPLETO
═══════════════════════════════════════════════════════════════════════════

Cenário: Você descobriu um router na rede

PASSO 1: Identifiquer
┌─────────────────────────────────────┐
│ IP: 192.168.1.1                     │
│ MAC: AA:BB:CC:DD:EE:FF             │

└─────────────────────────────────────┘

PASSO 2: Renomear
┌─────────────────────────────────────┐
│ Duplo-clique no MAC                 │
│ Janela: "Novo apelido:"             │

┌─────────────────────────────────────┐
│ Clique direito em "HTTP(80)..."     │
│ Menu: [ HTTP (80) ][ HTTPS (443) ]  │
│ Clique em "HTTP (80)"               │
│ ➔ Abre http://192.168.1.1:80       │
│ ➔ Interface web do router aparece  │
└─────────────────────────────────────┘

PASSO 4: Copiar Informações
┌─────────────────────────────────────┐
│ Clique na linha                     │
│ Ctrl+C                              │
│ Cola em um documento                │
│ ➔ Todos os dados da linha copiados │
└─────────────────────────────────────┘
