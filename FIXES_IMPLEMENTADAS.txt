PROBLEMAS CORRIGIDOS
────────────────────

1. BOTOES NAO APARECIAM NA JANELA DE EDICAO
   ─────────────────────────────────────────
   
   Problema:
   • Ao fazer duplo-clique em um nome de dispositivo, a janela abria
   • Porem, os botoes "Salvar" e "Cancelar" nao eram visiveis
   
   Causa:
   • dialog.geometry("350x140") era muito pequeno
   • A janela tinha altura insuficiente para exibir todos os elementos
   
   Solucao:
   • Aumentado de 350x140 para 400x180
   • Agora ha espaco suficiente para labels, entrada e botoes
   
   Arquivo: analisador_rede_gui.py, linha ~444
   
   ANTES:
     dialog.geometry("350x140")
   
   DEPOIS:
     dialog.geometry("400x180")

2. NOMES NAO ERAM CARREGADOS AO REABRIR A APLICACAO
   ────────────────────────────────────────────────
   
   Problema:
   • Ao editar um nome e fechar a aplicacao
   • Ao reabrir, o nome nao aparecia mais
   • config.json perdia a chave "device_nicknames"
   
   Causa Multipla:
   a) config.json nao tinha "device_nicknames" inicialmente
   b) _save_config() so salvava ping_attempts e scan_interval
   c) _load_config() nao garantia que "device_nicknames" existisse
   
   Solucoes Implementadas:
   
   a) ATUALIZAR _load_config() (linha ~255)
      ──────────────────────────────────────
      • Verifica se "device_nicknames" existe
      • Se nao existir, cria estrutura completa
      • Salva automaticamente config.json com todas as chaves
      • Garante que ping_attempts e scan_interval sempre existem
      
      Nova logica:
      - Carrega config.json
      - Se "device_nicknames" nao estiver: adiciona
      - Se "ping_attempts" nao estiver: adiciona valor padrao
      - Se "scan_interval" nao estiver: adiciona valor padrao
      - Retorna config completa
   
   b) ATUALIZAR _save_config() (linha ~279)
      ────────────────────────────────────────
      • Agora salva device_nicknames junto com outras configs
      • Preserva estrutura completa em cada salvo
      • Usa ensure_ascii=False para suportar acentuacao
      
      ANTES:
        config = {
            "ping_attempts": ...,
            "scan_interval": ...
        }
      
      DEPOIS:
        config = {
            "ping_attempts": ...,
            "scan_interval": ...,
            "device_nicknames": self.device_nicknames
        }
   
   c) ATUALIZAR config.json (estrutura inicial)
      ─────────────────────────────────────────
      • Adiciona "device_nicknames": {} na estrutura inicial
      • Garante que arquivo ja esta pronto para receber nomes
      
      {
        "ping_attempts": 6,
        "scan_interval": 5,
        "device_nicknames": {}
      }
