COMO USAR
═══════════════════════════════════════════════════════════════════════════

INICIAR APLICAÇÃO:
──────────────────
python run.py

A aplicação:
1. Carrega oui_database.json do cache (instantâneo)
2. Verifica se precisa atualizar (semanal)
3. Se precisar e tiver internet, baixa novo
4. Carrega device_nicknames de config.json
5. Inicia GUI com tudo pronto


ATUALIZAR OUI MANUALMENTE:
──────────────────────────
python atualizador_oui.py --force

Resultado:
✓ Download 3 MB
✓ Parse 38.536 OUIs
✓ Merge com nomes customizados
✓ Salva em oui_database.json
✓ Atualiza metadata


EDITAR NOME DE DISPOSITIVO:
───────────────────────────
1. Duplo-clique na coluna "Nome [Editar]"
2. Modal abre com IP, MAC, campo editável
3. Digite nome (ex: "Câmera Sala")
4. Enter ou clique "Salvar"
5. Salvo em config.json ✓
