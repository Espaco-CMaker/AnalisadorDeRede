ARQUIVOS DE CONFIGURAÇÃO
═══════════════════════════════════════════════════════════════════════════

1. oui_database.json
───────────────────
Contém o banco de dados OUI mapeado.

Tamanho: ~3 MB
Atualizações: Automático (1x por semana) ou manual via "python atualizador_oui.py --update"
Formato:

{
  "24:4B:03": {
    "fabricante": "Samsung Electronics Co.,Ltd",
    "tipo": "Smartphone/Tablet"
  },
  "00:1A:7D": {
    "fabricante": "Apple, Inc.",
    "tipo": "iPhone/iPad"
  },
  ...
}

2. oui_metadata.json
───────────────────
Metadados sobre as atualizações.

Exemplo:

{
  "ultima_atualizacao": "2026-01-25T20:21:37.134313",
  "fonte": "https://www.wireshark.org/download/automated/data/manuf",
  "total_ouis": 38536,
  "versao": "1.0"
}

3. config.json
──────────────
Configurações gerais + NOMES PERSONALIZADOS de dispositivos.

Exemplo:

{
  "ping_attempts": 4,
  "scan_interval": 60,
  "device_nicknames": {
    "24:4B:03:AA:BB:CC": "Celular Samsung",
    "00:1A:7D:BB:CC:DD": "iPad Maria",
    "00:1F:F3:11:22:33": "iPhone Do Jo",
    "00:0F:33:77:88:99": "Router Vivo"
  }
}

COMO FUNCIONA A PERSISTÊNCIA DE NOMES
═══════════════════════════════════════════════════════════════════════════

FLUXO NA INICIALIZAÇÃO:
────────────────────

1. Aplicação inicia
   └─> Carrega config.json
   └─> device_nicknames = {"MAC": "Nome", ...}

2. ARP scan descobre dispositivos
   └─> IP1 -> MAC1
   └─> IP2 -> MAC2
   └─> IP3 -> MAC3

3. Para cada dispositivo, ao exibir:
   └─> Extrai MAC
   └─> Procura em device_nicknames[MAC]
   └─> Se encontrar: exibe nome
   └─> Se não encontrar: campo vazio na coluna "Nome [Editar]"

FLUXO AO EDITAR UM NOME:
───────────────────────

1. Usuário faz duplo-clique na coluna "Nome [Editar]"
   └─> Janela modal abre

2. Modal exibe:
   └─> IP: 192.168.1.50
   └─> MAC: AA:BB:CC:DD:EE:FF
   └─> Campo editável com nome atual (se existir)

3. Usuário digita novo nome
   └─> Clica "Salvar" ou pressiona Enter

4. Sistema atualiza:
   └─> device_nicknames["AA:BB:CC:DD:EE:FF"] = "Novo Nome"
   └─> config.json é reescrito
   └─> Tabela atualizada imediatamente

5. Próximas execuções:
   └─> config.json carregado
   └─> Nome aparece automaticamente

VANTAGEM DO VÍNCULO COM MAC:
────────────────────────────
Se o IP do dispositivo mudar, o nome é mantido!

Exemplo:
  Seu router tem IP 192.168.1.1 com MAC AA:BB:CC:DD:EE:FF
  Você nomeou como "Router Principal"
  
  Semanas depois, o IP muda para 192.168.1.2
  O mesmo MAC aparece
  Nome "Router Principal" continua vinculado ao MAC!

FLUXO COMPLETO DE IDENTIFICAÇÃO
═══════════════════════════════════════════════════════════════════════════

Quando um dispositivo é descoberto:

1. ARP SCAN encontra:
   └─> IP: 192.168.1.50
   └─> MAC: AA:BB:CC:DD:EE:02

2. EXTRAI OUI:
   └─> AA:BB:CC (3 primeiros bytes)

3. CONSULTA OUI DATABASE (38.536 OUIs):
   └─> Busca "AA:BB:CC" em oui_database.json
   └─> Encontra: "HP Inc." / "Impressora"

4. APLICA HEURÍSTICAS:
   └─> Fabricante "HP" + tipo "Impressora"
   └─> Resultado refinado: "HP Printer" com confiança "Alto"

5. BUSCA NOME PERSONALIZADO:
   └─> Consulta config.json
   └─> Encontra: device_nicknames["AA:BB:CC:DD:EE:02"] = "Impressora HP"

6. EXIBE NA TABELA:
   └─> IP: 192.168.1.50
   └─> MAC: AA:BB:CC:DD:EE:02
   └─> Nome: "Impressora HP" ← Do config.json
   └─> Fabricante: "HP Inc." ← Do OUI database
   └─> Tipo: "HP Printer" ← Heurística aplicada

PRIORIDADE DE INFORMAÇÃO
═══════════════════════════════════════════════════════════════════════════

Na coluna "Nome":
  1. PRIMEIRO: Nome personalizado (config.json) ← MAIS IMPORTANTE
  2. Caso vazio: Campo editável
  3. Ao salvar: Persiste em config.json

Na coluna "Fabricante":
  1. PRIMEIRO: OUI database online (38.536 entradas)
  2. Fallback: Dados locais customizados
  3. Caso não encontre: "Desconhecido"

Na coluna "Tipo":
  1. PRIMEIRO: Heurística baseada em fabricante
  2. Fallback: Tipo do OUI database
  3. Caso vazio: Campo em branco

FAQ
═══════════════════════════════════════════════════════════════════════════

P: Quanto tempo leva para atualizar?
R: 30-60 segundos (depende da internet)

P: Preciso de permissão de admin?
R: Não, apenas para ARP scan. OUI atualiza como usuário normal.

P: Os nomes são sincronizados entre PCs?
R: Não. Cada PC tem seu config.json local. Use sincronização manual se necessário.

P: Se mudar o MAC de um dispositivo?
R: O nome antigo permanece vinculado ao MAC anterior. Use novo nome para novo MAC.

P: Posso editar config.json manualmente?
R: Sim, mas ferramenta pode sobrescrever. Faça backup antes.

P: O que acontece se desligar durante atualização OUI?
R: Mantém a versão anterior. Na próxima execução, tenta novamente.
