A nova funcionalidade permite identificar o nome provável e tipo de 
equipamento a partir de um endereço MAC Address, utilizando:

1. Base de dados de OUIs (Organizationally Unique Identifier)
2. Regras heurísticas baseadas em padrões de fabricantes
3. Análise inteligente de tipos de equipamento

═══════════════════════════════════════════════════════════════════════════
CONCEITOS FUNDAMENTAIS
═══════════════════════════════════════════════════════════════════════════

MAC ADDRESS (Media Access Control Address)
──────────────────────────────────────────
Estrutura: XX:XX:XX:XX:XX:XX (48 bits)
           └─OUI─┘ └─NIC─────┘

Exemplo: 24:4B:03:AA:BB:CC
         └─OUI─┘ └─NIC─────┘

OUI (Organizationally Unique Identifier)
────────────────────────────────────────
- 3 primeiros bytes (24 bits) do MAC
- Identifica o fabricante/fabricante do chip
- Mantido pela IEEE (Institute of Electrical and Electronics Engineers)
- Exemplo: 24:4B:03 = Espressif Systems

NIC (Network Interface Controller)
──────────────────────────────────
- Últimos 3 bytes (24 bits) do MAC
- Identificador único do dispositivo
- Atribuído pelo fabricante

═══════════════════════════════════════════════════════════════════════════
CLASSE: IdentificacaoEquipamento
═══════════════════════════════════════════════════════════════════════════

Estrutura de retorno com informações estruturadas:

@dataclass
class IdentificacaoEquipamento:
    mac_completo: str          # MAC normalizado (24:4B:03:AA:BB:CC)
    oui: str                   # OUI extraído (24:4B:03)
    fabricante: str            # Nome do fabricante (Espressif)
    tipo_equipamento: str      # Tipo identificado (ESP8266/ESP32 - IoT)
    confianca: str             # Nível de confiança (Alto/Médio/Baixo)

EXEMPLO DE USO:
───────────────
from analisador_rede import identificar_equipamento_por_mac

resultado = identificar_equipamento_por_mac("24:4B:03:AA:BB:CC")
print(resultado.fabricante)        # Espressif
print(resultado.tipo_equipamento)  # ESP8266/ESP32 - Sonoff/IoT
print(resultado.oui)               # 24:4B:03
print(resultado.confianca)         # Alto

# Converter para dicionário (JSON-ready)
dados_json = resultado.to_dict()

═══════════════════════════════════════════════════════════════════════════
FUNÇÕES PRINCIPAIS
═══════════════════════════════════════════════════════════════════════════

1. identificar_equipamento_por_mac(mac: str) → IdentificacaoEquipamento
────────────────────────────────────────────────────────────────────────

Identifica um único equipamento.

PARÂMETROS:
  mac (str): Endereço MAC em diversos formatos
             ✓ "24:4B:03:AA:BB:CC"  (padrão com dois-pontos)
             ✓ "244B03AABBCC"       (sem formatação)
             ✓ "24-4B-03-AA-BB-CC"  (com hífens)
             ✓ "24 4B 03 AA BB CC"  (com espaços)
             ✓ "244b03aabbcc"       (minúsculas)

RETORNA:
  IdentificacaoEquipamento com:
    - mac_completo: MAC normalizado
    - oui: Código OUI extraído
    - fabricante: Nome do fabricante
    - tipo_equipamento: Tipo identificado com heurísticas
    - confianca: Grau de certeza da identificação

EXEMPLOS:
─────────
>>> resultado = identificar_equipamento_por_mac("24:4B:03:AA:BB:CC")
>>> resultado.fabricante
'Espressif'

>>> resultado = identificar_equipamento_por_mac("00:1A:7D:BB:CC:DD")
>>> resultado.tipo_equipamento
'Smartphone/Tablet Galaxy'

>>> resultado = identificar_equipamento_por_mac("00:1F:F3:11:22:33")
>>> resultado.fabricante
'Apple'


2. identificar_multiplos_equipamentos(macs: Dict[str, str]) → Dict
─────────────────────────────────────────────────────────────────

Identifica múltiplos equipamentos em lote.

PARÂMETROS:
  macs (Dict[str, str]): Dicionário {IP: MAC}
                         {"192.168.1.1": "24:4B:03:AA:BB:CC", ...}

RETORNA:
  Dict[str, IdentificacaoEquipamento]: {IP: resultado, ...}

EXEMPLO:
────────
dispositivos = {
    "192.168.1.1": "00:0F:33:77:88:99",
    "192.168.1.10": "24:4B:03:AA:BB:CC",
    "192.168.1.20": "00:1A:7D:BB:CC:DD",
}

resultados = identificar_multiplos_equipamentos(dispositivos)

for ip, info in resultados.items():
    print(f"{ip}: {info.fabricante} - {info.tipo_equipamento}")

REGRAS HEURÍSTICAS
═══════════════════════════════════════════════════════════════════════════

As heurísticas refinam o tipo de equipamento baseado no fabricante:

PADRÃO DE HEURÍSTICA:
─────────────────────
Nome do Fabricante  →  Padrão de Reconhecimento  →  Tipo Refinado

EXEMPLOS IMPLEMENTADOS:
─────────────────────
Espressif          → "espressif"
                   → ESP8266/ESP32 - Sonoff/IoT/Sensor WiFi (Confiança: Alto)

Apple              → "apple" + "watch" em tipo_base
                   → Apple Watch - Smartwatch (Confiança: Alto)
                   → "apple" (genérico)
                   → iPhone/iPad/MacBook/Apple TV (Confiança: Médio)

Amazon             → "amazon"
                   → Amazon Echo/Alexa/Fire TV (Confiança: Alto)

Google             → "google" + "nest" em tipo_base
                   → Google Nest/Chromecast/Home (Confiança: Alto)
                   → "google" (genérico)
                   → Nexus/Pixel/Chromecast (Confiança: Médio)

Samsung            → "samsung" + "tv"
                   → Samsung Smart TV (Confiança: Alto)
                   → "samsung" (genérico)
                   → Smartphone/Tablet Galaxy (Confiança: Médio)

Arcadyan           → "arcadyan"
                   → Roteador/Modem/ONT de Operadora (Confiança: Alto)

Hikvision          → "hikvision"
                   → Câmera IP/NVR Hikvision (Confiança: Alto)

Dahua              → "dahua"
                   → Câmera IP/NVR Dahua (Confiança: Alto)

TP-Link            → "tp-link" + "access point"
                   → TP-Link Access Point/Repetidor (Confiança: Alto)
                   → "tp-link" (genérico)
                   → TP-Link Roteador/Switch/WiFi (Confiança: Médio)

HP/Hewlett-Packard → "hewlett" ou "hp"
                   → Impressora/Multifuncional HP (Confiança: Alto)

═══════════════════════════════════════════════════════════════════════════
NÍVEIS DE CONFIANÇA
═══════════════════════════════════════════════════════════════════════════

Alto
────
✓ OUI encontrado no banco de dados
✓ Heurística aplicada com sucesso
✓ Resultado muito provável está correto

Exemplo: Espressif com ESP8266/ESP32

Médio
─────
✓ OUI encontrado no banco de dados
✓ Tipo base sem heurística refinada
✓ Resultado provavelmente correto, mas pode ter variações

Exemplo: Apple com iPhone/iPad/MacBook (amplo)

Baixo
─────
✓ OUI encontrado mas tipo genérico
✓ Múltiplas possibilidades
✓ Requer verificação adicional

Exemplo: Broadcom (chipset, não equipamento final)

Desconhecido
────────────
✗ OUI não encontrado no banco de dados
✗ Equipamento não pode ser identificado
✗ Requer atualização do banco de dados

Exemplo: Novo fabricante não cadastrado

═══════════════════════════════════════════════════════════════════════════
TRATAMENTO DE ERROS
═══════════════════════════════════════════════════════════════════════════

A função trata diversos formatos e erros:

ENTRADA ACEITA:
───────────────
✓ "24:4B:03:AA:BB:CC"  - Padrão com dois-pontos
✓ "244B03AABBCC"       - Sem formatação
✓ "24-4B-03-AA-BB-CC"  - Com hífens
✓ "24 4B 03 AA BB CC"  - Com espaços
✓ Maiúsculas e minúsculas
✓ Mixes de formato

ENTRADA REJEITADA (Retorna tipo "Desconhecido"):
──────────────────────────────────────────────────
✗ "INVALID"              - Formato inválido
✗ "00:00:00:00:00"       - MAC incompleto
✗ "00:11:22:33:44:55:66" - MAC muito longo
✗ ""                     - Vazio

NORMALIZAÇÃO AUTOMÁTICA:
─────────────────────────
A função _normalizar_mac() converte automaticamente:

"244b03aabbcc"  →  "24:4B:03:AA:BB:CC"  (sem formatação → padrão)
"24-4B-03-AA-BB-CC"  →  "24:4B:03:AA:BB:CC"  (hífens → dois-pontos)

EXEMPLO 4: Integração com análise de rede

from analisador_rede import fazer_arp_scan, identificar_multiplos_equipamentos

# Faz varredura ARP
ip_local, mascara = "192.168.1.1", "255.255.255.0"

    "timestamp": "2026-01-25 10:30:00",
    "rede": f"{ip_local}/24",
    "dispositivos": {
        ip: info.to_dict() 
        for ip, info in resultados.items()
    }
}

with open("rede_identificada.json", "w", encoding="utf-8") as f:
    json.dump(dados, f, indent=2, ensure_ascii=False)

═══════════════════════════════════════════════════════════════════════════
LIMITAÇÕES E CONSIDERAÇÕES
═══════════════════════════════════════════════════════════════════════════

LIMITAÇÕES:
───────────
1. Banco de dados finito:
   ✓ Contém 100+ OUIs, mas não cobre todos os fabricantes
   ✓ Requer atualização periódica para novos OUIs

2. Heurísticas baseadas em padrões:
   ✓ Pode não identificar corretamente equipamentos raros
   ✓ Múltiplas possibilidades para um fabricante

3. OUI podem mudar de proprietário:
   ✓ IEEE permite transferência de OUIs
   ✓ Pode resultar em identificações imprecisas

4. Dispositivos com MAC falsificado (MAC spoofing):
   ✓ Não pode ser detectado por este módulo
   ✓ Resultaria em identificação incorreta

RECOMENDAÇÕES:
───────────────
✓ Combinar com verificação de DNS para melhor precisão
✓ Usar em conjunto com análise de serviços/portas
✓ Considerar contexto da rede (ex: rede corporativa, residencial)
✓ Atualizar banco de dados periodicamente
✓ Usar nível de confiança como indicador de certeza
