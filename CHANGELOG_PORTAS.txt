FUNCIONALIDADES IMPLEMENTADAS:

1. CLIQUE DIREITO NA COLUNA "SERVIÇOS"
   ───────────────────────────────────────────────────────────────────────
   • Clique direito em qualquer dispositivo na coluna "Serviços" abre um menu
   • Menu exibe todas as portas descobertas naquele dispositivo
   • Cada porta é um link clicável para abrir o serviço

2. PROTOCOLOS AUTOMÁTICOS
   ───────────────────────────────────────────────────────────────────────
   Mapeamento automático de protocolo por porta:
   
   HTTP/HTTPS:
   - 80    → http://IP:80
   - 443   → https://IP:443
   - 8000  → http://IP:8000
   - 8080  → http://IP:8080
   - 8443  → https://IP:8443
   - 8888  → http://IP:8888
   
   Serviços SSH/Telnet:
   - 22    → ssh://IP (protocolo SSH)
   - 23    → telnet://IP (protocolo Telnet)
   
   Bancos de Dados:
   - 3306  → http://IP:3306 (MySQL)
   - 5432  → http://IP:5432 (PostgreSQL)
   - 27017 → http://IP:27017 (MongoDB)
   
   Serviços de Rede:
   - 21    → ftp://IP (FTP)
   - 53    → DNS (port 53)
   - 3389  → RDP (Remote Desktop)
   - 5900  → VNC (Virtual Network Computing)
   - 6379  → Redis (Cache)
   
   Fallback: Qualquer porta desconhecida abre como http://IP:PORTA

3. THREADING PARALELO
   ───────────────────────────────────────────────────────────────────────
   • Cada porta é testada em thread separada (ThreadPoolExecutor)
   • 20 workers para 27 portas comuns (2 threads por porta em média)
   • 50 workers para full range scan (1-1024)
   • Timeout configurável por porta (0.5s padrão, 0.3s full range)

EXEMPLO DE EXECUÇÃO:

Tabela original:
┌─────┬──────────────┬──────────────────┬──────────┬────────────────┐
│ IP  │ MAC Address  │ Hostname         │ Serviços │ Ping           │
├─────┼──────────────┼──────────────────┼──────────┼────────────────┤
│192.│ AA:BB:CC:DD  │ router.local     │HTTP(80) │ 2ms (100%)     │
│    │              │                  │SSH(22)  │                │
└─────┴──────────────┴──────────────────┴──────────┴────────────────┘

Ao clicar direito em "HTTP(80), SSH(22)":
┌──────────────────────────────────┐
│ Portas de 192.168.1.1            │
├──────────────────────────────────┤
│ HTTP (80)        ← clicável      │
│ SSH (22)         ← clicável      │
└──────────────────────────────────┘

Clicando em "HTTP (80)":
→ Abre: http://192.168.1.1:80 no navegador padrão

Clicando em "SSH (22)":
→ Tenta: ssh://192.168.1.1 (protocolo SSH)
