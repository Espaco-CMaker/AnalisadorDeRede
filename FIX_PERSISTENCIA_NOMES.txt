═══════════════════════════════════════════════════════════════════════════

PROBLEMA IDENTIFICADO
─────────────────────

Ao editar o nome de um dispositivo na coluna "Nome [Editar]", o nome não
era persistido em config.json quando você fechava e reabia a aplicação.

CAUSA RAIZ
──────────

1. O arquivo config.json não continha a chave "device_nicknames" inicialmente
2. A função _save_nicknames() não preservava ping_attempts e scan_interval
   ao salvar os nomes
3. O dicionário não era inicializado corretamente na primeira edição

SOLUÇÃO IMPLEMENTADA
────────────────────

1. ATUALIZAR config.json
   ───────────────────
   Agora inclui a chave "device_nicknames" vazia:

   {
     "ping_attempts": 6,
     "scan_interval": 5,
     "device_nicknames": {}
   }

   ✓ Estrutura completa inicializada
   ✓ Pronta para receber nomes de dispositivos
   ✓ Preserva configurações de ping

2. MELHORAR _save_nicknames()
   ────────────────────────
   A função agora:
   - Preserva ping_attempts e scan_interval
   - Preserva outras configurações existentes
   - Escreve corretamente o dicionário device_nicknames
   - Usa ensure_ascii=False para suportar caracteres especiais
   - Inclui debug message para verificação

   Código atualizado:
   
   def _save_nicknames(self):
       """Salva apelidos de dispositivos no arquivo de configuração"""
       try:
           config = {
               "ping_attempts": self.ping_attempts.get(),
               "scan_interval": self.scan_interval.get()
           }
           
           # Carrega config existente para não perder outras configurações
           if os.path.exists(self.config_file):
               try:
                   with open(self.config_file, "r", encoding="utf-8") as f:
                       existing = json.load(f)
                       for key in existing:
                           if key not in config:
                               config[key] = existing[key]
               except:
                   pass
           
           config["device_nicknames"] = self.device_nicknames
           
           with open(self.config_file, "w", encoding="utf-8") as f:
               json.dump(config, f, indent=2, ensure_ascii=False)
               
           print(f"[DEBUG] Config salvo: {len(self.device_nicknames)} nomes salvos")
       except Exception as e:
           print(f"Erro ao salvar apelidos: {e}")
